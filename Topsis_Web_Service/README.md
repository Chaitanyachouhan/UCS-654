# TOPSIS Web Service (Flask Implementation)

## 📌 Project Overview
This project implements the TOPSIS (Technique for Order Preference by Similarity to Ideal Solution) method as a web service using Flask.

Users can:
- Upload a CSV file
- Provide weights
- Provide impacts (+/-)
- Enter email ID
- Receive ranked TOPSIS results via email

---

## 🚀 Features

- CSV file upload
- Automatic delimiter detection
- Input validation
- Email validation
- TOPSIS score calculation
- Ranking of alternatives
- Result sent via email as CSV attachment
